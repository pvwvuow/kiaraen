# Design — طرح‌های مصوب رابط کاربری

این پیش‌نمایش‌ها از پروتوتایپ HTML مصوب (`kiara-app`) گرفته شده‌اند و مرجع ظاهری اپ اندروید هستند.

| فایل | صفحه | نکته |
|---|---|---|
| `ui-home.png` | خانه | پوشه ادامه یادگیری + کتاب شناور + استریک |
| `ui-login.png` | ورود | حاشیه طلایی = حالت فوکوس فیلد |
| `ui-signup.png` | ثبت‌نام | چک‌باکس قوانین + «حداقل ۸ کاراکتر» |

پالت دقیق (مطابق `:root` قالب):
`--gold #FEC60D` · `--gold-d #F0A900` · `--ink #1C1A17` · `--mut #9C968B` · `--bg #F7F6F3`
